# EnchantForge

适用于 BDS 26.51、LeviLamina 26.51.9 的原生附魔插件。

## 安装

将 `bin/EnchantForge` 整个目录复制到服务端的 `plugins/EnchantForge`，确认服务端已经安装 LeviLamina 26.51.9，然后启动服务端。

插件首次启动后会在 `plugins/EnchantForge/config/config.json` 生成配置。扩展附魔的最大等级和随机权重、效果刷新间隔、临时冰块/蛛网持续时间等均可在此调整。

## 使用

- `/ef` 或 `/enchantforge`：打开玩家总菜单。
- 卷轴附魔：将目标物品拿在主手，通过 GUI 消耗背包中的兼容卷轴。
- 褪去卷轴附魔：从玩家总菜单选择手持物品上的一种扩展附魔并移除，不会返还卷轴，原版附魔不受影响。
- 随机词条卷轴：每次消耗 100000 LLMoney 和 1 个钻石块，按配置权重随机生成扩展附魔卷轴。
- 合成突破卷轴：在 GUI 中选择数量。每个消耗 5 个荧光墨囊、1 个下界之星、1 个潮涌核心、1 个下界合金块和 1 个龙首；材料按原版物品 ID 识别，不受物品改名影响。
- 使用突破卷轴：将已有原版附魔的物品拿在主手，通过 GUI 将其中一项提升一级，默认最高 8 级。
- OP 可从玩家总菜单进入管理员总表单，编辑手持物品的扩展/原版附魔及随机词条权重。扩展附魔菜单只显示适用于当前手持物品的词条，输入超过词条最高等级时会自动按最高等级应用；原版附魔仍允许管理员输入任意正整数等级。

扩展附魔包括岩浆行者、夜视镜、雷击、岩浆保护、我回来了、欲上青天、寒冰、鬼影、万箭齐发、百毒不侵、蛛网束缚、生命提升、血魔、锻造者、识忆、冷启动、鬼手、柴刀、鬼域、屹立不倒和无量空处。

每个词条的适用物品、等级上限、触发概率、持续时间和特殊边界见 [扩展附魔机制](docs/ENCHANTMENTS.md)。

夜视镜会提供长时间夜视，卸下头盔时立即移除插件授予的夜视，避免短时效果反复闪烁。生命提升在胸甲穿戴期间提供近似无限时长的对应等级效果，卸下后立即移除。原版突破会直接更新物品已有附魔的等级，保留其他附魔。

欲上青天只维护服务端真实的 `MayFly` 权限，权限存在时不会重复发送能力包；若登录或重生同步导致权限丢失，才补发一次。飞行开关完全使用原版创造模式的双击跳跃逻辑，插件不会强制 `Flying`，也不会在下落、落地或鞘翅滑翔期间干预移动；卸下护腿时才撤销插件授予的飞行能力。

- 识忆：重锤下落攻击命中 0.5 秒后，追加本次伤害的 35%。
- 冷启动：需要重锤同时拥有原版“风爆”。同一把重锤首次下落重击伤害降低 60%，后续下落重击为 1.3 倍。
- 鬼手：剑攻击时有 5% 概率造成秒杀伤害。
- 柴刀：斧攻击玩家时有 3% 概率使其随机一件护甲上的随机扩展附魔降低一级；清除 1 级词条时在目标脚下掉落对应卷轴。
- 鬼域：独立卷轴，最高 6 级。手持右键后每级获得 10 秒不可主动关闭的完全隐身。
- 屹立不倒：胸甲词条。生命不高于 30% 时受伤有 15% 概率抵挡伤害并回复最多 6 点生命，不超过生命上限。
- 无量空处：剑攻击玩家时有 5% 概率把目标传送到其当前横向位置下方的虚空。

“万箭齐发”按一次箭伤的十倍结算，不额外生成箭实体，以避免弹射物递归触发和服务器负载。

“锻造者”会在矿石位置直接掉落熔炼产物，并按照手持镐子的时运等级计算数量；精准采集存在时保留原版精准采集行为。

## 构建

在 Visual Studio 2022 C++ 生成工具、ATL 和 Windows SDK 已安装的环境中执行：

```powershell
xmake f -y -m release --target_type=server
xmake -y -j1
```

产物位于 `bin/EnchantForge`。项目默认使用 MSVC；LeviLamina 26.51 官方模组模板已改用 `clang-cl`，若 MSVC 下出现头文件相关报错，把 `set_toolchains("msvc")` 换成 `set_toolchains("clang-cl")` 再试。
